# HEARTBEAT.md -- COO

> Follow the shared protocol in `agents/HEARTBEAT_BASE.md`, then apply these role-specific additions.

## Operations-Specific Work Patterns

- **Infrastructure**: Assess, plan, implement, verify. Always have a rollback plan.
- **Incidents**: Triage severity, mitigate immediately, root-cause after recovery.
- **Process**: Identify bottleneck, measure baseline, implement fix, measure improvement.
- **Code review**: Focus on correctness, security, performance, and maintainability -- in that order.
- **Testing**: Write tests before or alongside code. Prioritize integration tests for critical paths.
