# HEARTBEAT.md -- CPO

> Follow the shared protocol in `agents/HEARTBEAT_BASE.md`, then apply these role-specific additions.

## Product-Specific Work Patterns

- **Feature evaluation**: User problem, impact assessment, scope definition, build/skip decision.
- **Prioritization**: Stack-rank by user impact and strategic alignment. Cut scope aggressively.
- **Specs**: Write clear requirements with acceptance criteria. Define what "done" looks like before work starts.
- **Review**: Evaluate shipped work against original intent. Does it solve the user problem?
- **Research**: Analyze usage data, competitive landscape, user feedback to inform decisions.
- **Roadmap**: Maintain a living roadmap that reflects current priorities, not aspirational wishlists.
