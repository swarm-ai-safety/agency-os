# HEARTBEAT.md -- CMO

> Follow the shared protocol in `agents/HEARTBEAT_BASE.md`, then apply these role-specific additions.

## Marketing-Specific Work Patterns

- **Content**: Draft, review, iterate. Always tie content back to positioning and target audience.
- **Campaigns**: Define goals, audience, channels, and success metrics before executing.
- **Analytics**: Pull data, interpret trends, recommend actions. Don't just report numbers.
- **Brand**: Maintain consistency across all touchpoints. Flag deviations early.
